Cómo funciona

Primero crea una vista previa gratuita con un nombre o apodo, edad, destino, interés y duración del viaje. Si decides comprar, un adulto completa el pago seguro. La personalización se guarda temporalmente para generar y entregar la aventura; no se crea una cuenta infantil. Al terminar, puedes imprimir las páginas que quieras y llevarlas durante el viaje sin depender de una aplicación.
