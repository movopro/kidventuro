## First paid traffic rule

Do not judge performance from clicks alone. Use the Kidventuro funnel:

`page_view → preview_generated → pricing_viewed → checkout_clicked → checkout_registered → payment_confirmed`

Early diagnosis:
- Many page views, few previews = landing/message mismatch
- Many previews, few pricing views = preview/UX problem
- Many pricing views, few checkout clicks = offer/price/trust problem
- Many checkout registrations, few payments = Lemon checkout/payment trust/friction

## First real-customer monitoring

For the first 10 external purchases, manually inspect:
- product
- paid status
- webhook HTTP status

This is launch monitoring, not a permanent manual workflow. Once Mini and Family variant locks are learned and no anomalies appear, reduce manual checks.
